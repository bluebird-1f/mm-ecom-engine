ประเภทของ Type ที่ใช้บ่อย:

feat: เพิ่มฟีเจอร์ใหม่ (Feature)
fix: แก้ไขบั๊ก (Bug fix)
refactor: ปรับแต่งโค้ดให้สะอาดขึ้นโดยไม่เปลี่ยนพฤติกรรมของโปรแกรม
style: แก้ไขเรื่องรูปแบบ เช่น ช่องว่าง, เว้นวรรค, จัดฟอร์แมต (ไม่มีผลต่อการทำงานของโค้ด)
docs: แก้ไขเอกสาร เช่น README.md
test: เพิ่มหรือแก้ไข Test
chore: งานทั่วไปที่ไม่เกี่ยวกับการแก้ไขโค้ดหลัก เช่น อัปเดต dependencies, ตั้งค่า build tool
