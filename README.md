# English  
## Rootname :  
mm-ecom-engine  
## **Project name** :  
Multi-Modal E-Commerce Analytics &amp; Intelligence Engine  
## **Target** :  
To understand the big picture. Data Science, Machine Learning and Deep Learning in one system  
* ## **What i will learn** :  
    * ### *Data Science* :  
    Data Cleaning, EDA, Feature Engineering, Handling Missing/Imbalanced Data

    * ### *Classical ML* :  
    Tabular Data Modeling (XGBoost/LightGBM) to predict LTV (Lifetime Value) and Churn Rate

    * ### *Deep Learning & NLP* :  
    Sentiment Analysis from product review (Transformers / BERT)

    * ### *Computer Vision* :  
    Image Classification to categorize product (CNN / ResNet)

    * ### *Deployment* :  
    Dockerize API with FastAPI and create Dashboard with Streamlit

## **Tech Stack** :  
Python, Pandas, Scikit-Learn, PyTorch/TensorFlow, HuggingFace, FastAPI, Docker
