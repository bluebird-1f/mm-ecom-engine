# <span style="color:#87CEFA;">mm-ecom-engine  </span>  
## **Project name** :  
Multi-Modal E-Commerce Analytics &amp; Intelligence Engine  
## **Target** :  
ทำความเข้าใจภาพรวม Data Science, Machine Learning และ Deep Learning ในระบบเดียว  
* ## **What i will learn** :  
    * ### *Data Science* :  
    Data Cleaning, EDA, Feature Engineering, Handling Missing/Imbalanced Data

    * ### *Classical ML* :  
    Tabular Data Modeling (XGBoost/LightGBM) เพื่อทำนาย LTV (Lifetime Value) และ Churn Rate

    * ### *Deep Learning & NLP* :  
    Sentiment Analysis จากรีวิวสินค้า (Transformers / BERT)

    * ### *Computer Vision* :  
    Image Classification สำหรับจัดหมวดหมู่ภาพสินค้า (CNN / ResNet)

    * ### *Deployment* :  
    Dockerize API ด้วย FastAPI และทำ Dashboard ด้วย Streamlit

## **Tech Stack** :  
Python, Pandas, Scikit-Learn, PyTorch/TensorFlow, HuggingFace, FastAPI, Docker
